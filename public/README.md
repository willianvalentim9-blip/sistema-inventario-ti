# Diretório Public

Este diretório contém as páginas públicas e pontos de entrada do sistema.

## Estrutura

- **dashboard.php** - Dashboard principal do sistema (requer autenticação)

## Notas

- Este diretório deveria ser o document root do servidor web em produção
- Atualmente o document root ainda é a raiz do projeto para compatibilidade
- O index.php na raiz redireciona para as páginas apropriadas
