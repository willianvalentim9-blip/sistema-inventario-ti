🎯 COMO USAR

1. FAZER BACKUP VIA SETTINGS
   → Acesse: http://localhost/sistema4/settings.php
   → Clique: "Fazer Backup Agora"
   → Arquivo é salvo em: /backups/backup_YYYY-MM-DD_HH-MM-SS.sql
   → Mensagem de sucesso aparece

2. FAZER BACKUP VIA POWERSHELL
   → Execute: powershell -ExecutionPolicy Bypass -File backup_database.ps1
   → Arquivo criado em: C:\xampp\htdocs\sistema4\backups\
   → Tamanho e status exibidos

3. VER GARANTIA DO PRODUTO
   → Acesse: http://localhost/sistema4/products.php
   → Clique em um produto
   → Botão "Visualizar"
   → Veja o novo card de garantia
   → Mesmo design das máquinas
