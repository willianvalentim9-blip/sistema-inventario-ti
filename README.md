# Sistema de Estoque de TI

Este é o sistema de estoque de TI atualizado, contendo as últimas correções e melhorias.

## Conteúdo:
- Código-fonte completo do sistema PHP/Bootstrap.
- Estrutura do banco de dados SQL.
- Documentação de instalação.

## Funcionalidades Principais:
- Gerenciamento de produtos e máquinas prontas.
- Upload de imagens.
- Scanner QR/Código de Barras.
- Geração automática de IDs para produtos e máquinas.
- Edição de máquinas prontas.
- Redução rápida de estoque.

Para instruções detalhadas de instalação, consulte o arquivo `INSTALACAO.md`.
