📋 PROBLEMA IDENTIFICADO

Ao editar máquina e ativar garantia, os dados não apareciam na página de
garantias (warranties.php). Isso acontecia porque o arquivo includes/warranties.php
só buscava dados da tabela "products", ignorando a tabela "ready_machines".

═════════════════════════════════════════════════════════════════════════════

🔧 SOLUÇÃO IMPLEMENTADA

Arquivo: includes/warranties.php

1. QUERY ANTERIOR (Apenas Produtos):
   SELECT * FROM products WHERE has_warranty = 1

2. QUERY NOVA (Produtos + Máquinas com UNION):
   SELECT id, name, category, model, manufacturer, warranty_provider, 
          warranty_start_date, warranty_end_date, status, 'product' as item_type
   FROM products 
   WHERE has_warranty = 1
   UNION ALL
   SELECT id, name, NULL, NULL, NULL, warranty_provider, 
          NULL, NULL, status, 'machine' as item_type
   FROM ready_machines 
   WHERE has_warranty = 1
   ORDER BY warranty_end_date ASC
